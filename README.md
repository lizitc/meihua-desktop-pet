# 御园莓华 · AI 桌面伙伴与全职助手

一只住在桌面上的犬系女仆。连上你自己的 AI 接口之后，她的一举一动都由 AI 决定。她能做这些事：

- 陪你聊天，也能开口说话。
- 管理日程、待办、提醒和例行任务，到点会主动来叫你。
- 在「工坊」里像 Claude Code 一样替你完成电脑上的工作。任务在后台跑，随时可以在聊天里问她进度。
- 给自己写新技能，或者写新的扩展工具。这些都要等你审核通过才会生效。

```
meihua-desktop/
├─ src/main/        主进程：窗口、AI、日程、工坊、扩展、语音
├─ src/renderer/    pet/ 桌宠渲染器 · panel/ 「莓华手账」管理界面
├─ assets/          角色素材（由交接包整理而来）与应用图标
├─ docs/            GPT-image 提示词包
└─ scripts/         素材整理、依赖打包、语法检查
```

## 运行

**直接安装**：运行 `dist/Meihua-Setup-1.0.0.exe`。可以自选安装目录，会创建桌面和开始菜单快捷方式。

**从源码运行**：需要 Node 20+。本机已放了便携版，在 `../.tools/node`。

```bash
npm install
```

```bash
npm start
```

**重新打包**：

```bash
npm run dist
```

产物在 `dist/`：`win-unpacked/` 是免安装版，`Meihua-Setup-<版本>.exe` 是安装包。

> 打包时如果出现 `Cannot create symbolic link` 报错，原因是 Windows 没开「开发者模式」，electron-builder 解压签名工具时建不了符号链接。打开开发者模式，或者把 `%LOCALAPPDATA%\electron-builder\Cache\winCodeSign\*.7z` 手动解压到同目录下的 `winCodeSign-2.6.0` 文件夹即可。缺的那两个文件是 macOS 用的，不影响 Windows 打包。

## 第一次打开

程序会先弹出欢迎向导，一共 4 步：

1. **认识一下**：告诉她怎么称呼你。
2. **连接 AI**：选一个服务商，填好 Key 和模型，点「测试连接」。
3. **声音**：可以先跳过。
4. **相处方式**：设置自由走动、总在最前等选项。

支持的接口：

| 类型 | 预设 |
|---|---|
| Claude 原生协议 | Anthropic 官方、自定义网关 / 中转 |
| OpenAI 兼容协议 | OpenAI、DeepSeek、通义千问、Kimi、智谱 GLM、硅基流动、OpenRouter、Gemini、自定义 |
| 本地模型（无需 Key） | Ollama、LM Studio |

使用 Claude 官方接口时，默认开启了**服务端备用模型**：主模型繁忙时，由官方自动换备用模型回答。在「设置 → AI 连接」里可以关掉。

工坊可以和聊天共用同一个模型，也可以单独配一个更强的模型，在「设置 → 工坊」里切换。

## 和她相处

| 操作 | 效果 |
|---|---|
| 右键**单击** | 打开花环菜单：聊天、手账、动作、隐藏…… |
| **按住**右键拖动 | 把她搬走。支持多显示器、负坐标和不同 DPI |
| 双击 | 弹出输入框，直接说话 |
| 左键摸头、碰耳朵、拉尾巴、点裙摆 | 部位互动，她会有反应。连上 AI 后反应由 AI 决定 |
| 按住 Ctrl 在她身上滚动滚轮 | 调整大小 |
| `Ctrl+Alt+J` | 叫她出来说话 |
| `Ctrl+Alt+H` | 打开「莓华手账」 |
| `Ctrl+Alt+M` | 显示 / 隐藏桌宠 |

快捷键可以在「设置 → 应用」里改。如果被其他程序占用，那一项会标红提示。

「允许自由走动」「固定位置 / 禁止拖动」「显示莓华」是三个互相独立的开关。托盘菜单和手账侧栏里都能找到。

站着的时候她会柔和地眨眼，眼睛跟着鼠标转，耳朵、头发、裙摆和尾巴也有细微的动作。

她还会自己散步、坐下或者睡觉，久不动会自动去睡。走路前会先原地转身，停下时再转回来。

## 「莓华手账」

| 页面 | 内容 |
|---|---|
| 今天 | 问候与当日摘要、时间线、待办、近一周安排、提醒；「播报」让她念今天的安排 |
| 聊天 | 完整对话记录，可以发图片，能看到她调用了哪些工具；支持「新话题」 |
| 日程 | 月历。双击日期新建；支持全天、重复（按天、周、月、年，可选星期几）、提醒和颜色 |
| 待办与提醒 | 待办（按逾期、今天、本周分组）· 一次性或重复提醒 · 例行任务（每天定时让她做一件事，比如查天气） |
| 工坊 | 后台任务。左边是任务架，右边是计划进度、每一步的执行记录和产出文件；可以中途发消息给她或喊停 |
| 技能与扩展 | 技能是写给她的做事方法（Markdown），扩展是她能调用的新工具（JavaScript）；底部是全部工具索引 |
| 记忆 | 她记住的关于你的事。可以置顶、修改或让她忘掉 |
| 设置 | AI 连接、声音、桌宠、关怀（早安播报、晚间回顾、久坐、喝水、睡前、免打扰）、工坊、应用 |

在聊天里直接说也行，例如：

- 「明天下午三点和小林开会，提前半小时提醒我」
- 「每个工作日早上八点帮我看看天气，下雨就提醒我带伞」
- 「帮我把 D:\照片\未整理 按拍摄月份分好文件夹」：会交给工坊，之后可以问她「做到哪了」
- 「以后我说『番茄钟』，你就提醒我 25 分钟后休息」：她会把这个做法写成一个新技能

## 声音

语音合成（TTS）支持这几种来源，「设置 → 声音」里可以试听：

- Windows 系统语音
- OpenAI 兼容的 `/audio/speech` 接口
- 本地 GPT-SoVITS（适合用自己训练的音色）
- Azure 语音
- 自定义 HTTP 接口

她说话时嘴巴会跟着音量动。

语音输入要另外打开，用的是 Whisper 兼容的识别接口。

## 安全设计

- **密钥**：API Key 用 Windows DPAPI（Electron safeStorage）加密，单独存放，不写进 `settings.json`。界面上只显示「已加密保存」，不会再回显。
- **工坊权限**有三档：
  - 「每步都问我」：读写文件和执行命令都要你点同意。
  - 「自动改文件」：改文件不用问，执行命令仍然要问。
  - 「全自动」。
  - 不管哪一档，下面这些高危命令都**一定会问**：递归删除整个盘或用户目录、格式化或分区、改启动项、删注册表、关机，以及下载后直接执行脚本。
- **AI 写的技能和扩展**：一律默认停用，要在「技能与扩展」里审核代码后手动启用。扩展的代码改动后会自动回到停用状态，需要重新审核。
- **扩展运行环境**：扩展跑在单独的 utilityProcess 里，崩溃不会影响主程序。
- **数据位置**：所有数据都在本机，默认在 `%APPDATA%\御园莓华`。「设置 → 应用」里能直接打开这个文件夹。

## 命令行参数（开发与测试用）

| 参数 | 用途 |
|---|---|
| `--data-dir=<目录>` | 把数据放到指定目录，适合便携使用或建第二个档案 |
| `--selftest=<目录>` | 自检：截下桌宠各种状态的图，并记录渲染错误。数据放在临时目录，不会动你的真实数据 |
| `--selftest-walk` | 自检时额外录制散步的连续帧 |
| `--selftest-panel` | 自检时截下手账全部页面，包括深色模式 |
| `--selftest-func` | 配合 `--selftest-panel` 使用。用内置的模拟模型跑通几条真实流程：界面上加待办、聊天和工具调用、工坊审批与写文件、扩展审核与调用 |
| `--selftest-ai` | 用模拟模型检查 AI 驱动的桌宠行为 |

```bash
npx electron . --selftest=./selftest-out --selftest-panel --selftest-func
```

`npm run check` 会对全部源码做语法检查。
