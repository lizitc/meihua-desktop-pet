# 走路动画重制工具包

## 旧版为什么不好看

我逐帧看了旧的走路素材，问题集中在三处：

| 问题 | 原因 |
|---|---|
| 画风、角色还原度差 | 8 张关键帧是在**同一张图里一起画的小人**（4×2 精灵图），每个人物只有约 420～480px 高，放大后脸发糊、五官走样；侧身角度也是模型自己猜的，没有定稿可参照 |
| 帧与帧对不上 | 关键帧和补帧分好几批生成，腿的粗细、胯的高度、裙长、头发蓬松度每批都不一样，播放起来人在「抖」 |
| 不流畅 | 15 张原画的时间间隔不均匀（3～7 帧不等），再用 RIFE 插成 64 帧。腿交叉处被插值抹成糊状，动作一快一慢；两只手全程握拳伸在前面，显得僵硬 |

## 这次怎么做

1. **先定侧身模型**：先画一张 3/4 侧向右的站立定稿，由你挑选。之后每一帧都锁定参照这张图，从源头上保证还原度。
2. **一张图只画一个人，全分辨率**：每帧单独出 1024×1536 的图，人物约 1400px 高，比旧版清晰将近 3 倍。
3. **几何姿势引导图**：16 张姿势引导图是程序按步态计算出来的，所以：
   - 脚底统一落在同一条地面线上；
   - 支撑脚的后移速度恒定，她在屏幕上走时不会「滑步」；
   - 身体起伏规律（下沉 → 经过 → 抬起）；
   - 手臂反向摆动，手是张开放松的。
4. **16 张真画，不用 AI 插帧**：每一帧都是完整的画，不会再有抹糊的腿。先画 8 张关键帧，确认后再画中间的 8 张。程序里以约 14 fps 均匀播放，一个循环 1.12 秒。横向移动按每一帧支撑脚的实测位置逐帧推进，脚踩在桌面上不会打滑。

`guides/overview.png` 是 16 帧引导图的总览，`guides/onion.png` 是全部姿势叠在一起的洋葱皮图，可以先看看步态是否合心意。

## 你需要做的

把整个 `art/walk-kit/` 文件夹交给 Codex，分阶段让它执行。每一步对 Codex 说：

> 读取 `art/walk-kit/CODEX-TASK.md`，执行 Stage 1。

| 阶段 | Codex 产出 | 你来做 |
|---|---|---|
| Stage 1 | 4 张 3/4 侧身定稿候选 `out/1-base/` | 挑一张最像莓华的，复制成 `refs/walk-base.png`；都不满意就让它再出几张 |
| Stage 2 | 8 张关键帧 `out/2-keys/`，外加总览图和预览 GIF | 把 `out/2-keys/` 发给我：我去掉绿底、对齐，放进程序里给你看实际效果，并标出哪几帧需要重画 |
| Stage 2b / 2c | 按测量结果修正个别关键帧（2b 改起伏，2c 改脚的前后位置） | Codex 每次重画都用 `tools/feet_check.py` 自己量脚位，合格的才保留 |
| Stage 3 | 8 张中间帧 `out/3-inbetweens/`（同样每张用 `tools/feet_check.py` 自检支撑脚位置） | 告诉我跑完了，我合成最终 16 帧动画 |
| Stage 3b | 只重画 W05、W13 的摆动腿，让迈步的脚匀速前移，不再一帧内猛地前冲 | 告诉我跑完了，我重新合成、打包 |
| Stage 4（已完成，v2） | 起步、停步的原地转身：向右 `T1`–`T3`、向左 `T1L`–`T3L` 各 3 张，每张都在相邻画面上修改得到；结果见 `out/4-turn/REPORT.md`，第一版留在 `out/4-turn/v1/` | 已接入程序：「正面立绘 → T1 → T2 → T3 → 侧身定稿」约 0.29 秒原地转身，起步时转过去再迈步，停步时倒放；向左单独绘制，蝴蝶结和尾巴不再左右跳 |

> 千万不要跳过 Stage 1 的挑选。定稿越像，后面每一帧就越像。

整个流程大约需要 17 张成品图。算上重试，Codex 预计会生成 40～60 次。

## 我收到图之后会做的

- 抠除绿底并去掉绿色溢边，检查白发、白袜边缘在深色和浅色桌面上都干净。
- 把颜色对齐到原立绘：生成的画普遍偏粉、偏饱和，白发和白袜带粉色，轮廓线偏浅。程序按原立绘逐帧校正亮度、饱和度和轮廓深浅，并按桌宠实际显示的大小再校一遍。所以生成时不必为颜色反复重试。
- 按地面线和身体中线逐帧对齐，统一缩放，换算成程序用的画布。
- 根据支撑脚的实际位置计算每帧的横向移动量，保证走起来不滑步。
- 如果脸部在帧与帧之间仍有细微跳动，我可以把同一个头部贴到每一帧上（跟随身体起伏），彻底锁定五官。
- 替换程序里的向右、向左两个走路循环，更新起步、停步逻辑，跑自检后重新打包。

向左走默认是把向右的画面镜像过来。镜像后，左耳上的两个蝴蝶结会跑到另一只耳朵上（侧身时那只耳朵大部分被遮住，不太显眼）。如果你很在意，之后可以用同一套引导图再画一组向左的。

## 文件说明

```
art/walk-kit/
├─ CODEX-TASK.md          给 Codex 的完整任务（英文提示词，分阶段）
├─ tools/feet_check.py    脚位测量（支撑脚、摆动脚的位置和抬高），Codex 每次出图后自检用
├─ refs/
│  ├─ ich01A_101.png      定稿立绘（角色与画风的唯一标准）
│  ├─ portrait.png        脸部特写
│  └─ scale-reference.png 定稿放在目标画布上的样子（尺寸与地面线基准）
├─ guides/
│  ├─ guide-BASE.png      Stage 1 侧身站立
│  ├─ guide-W00…W15.png   16 帧姿势引导（偶数 = 关键帧，奇数 = 中间帧）
│  ├─ overview.png        总览
│  ├─ onion.png           洋葱皮叠图
│  └─ stats.json          每帧身体高度与支撑脚位置（我合成时用）
└─ out/                   Codex 的产出（自动创建）
```

引导图由 `scripts/walk-guides/` 生成。想调整步幅、抬脚高度或起伏幅度，我改参数后重新生成即可。
