# 耳朵违和感修复（2026-11-11）

## 原因
- 耳朵的隐藏补全层（`ear-*-hidden.png`）是从原图里抠出来的，里面混进了右耳的粉色和深蓝蝴蝶结碎片、描边细线，以及一块半透明的"幽灵耳"。耳朵一摆动，这些东西就会露出来。
- 右耳的蝴蝶结是一张单独的图，它和耳朵沿着抗锯齿边切开。两张图各自绘制时，接缝处会透出背景，即使静止也能看到一圈细线。
- 拉动耳朵时最大会转到 0.36×1.25 ≈ 26°。垂耳抬到这个角度已经不像一片软布，而像折断了。

## 修复
- 运行 `node scripts/ear-clean.mjs`：
  - 隐藏层只保留与耳朵相连的实心耳色部分：在根部（头箍下）保留宽一些的带，其余地方只保留靠近耳朵边缘的窄带。
  - 蝴蝶结碎片用周围的耳色覆盖，细线和幽灵耳直接删除。
  - 把蝴蝶结并入右耳底图（两者 alpha 相加，因为它们本来就是原图的一个划分），蝴蝶结图层仍然画在上面，接缝因此消失。
  - 原图备份在 `orig/`。
- `rig.js` 的改动：
  - 耳朵角度上限改为 0.22（约 12.6°），拉动时不再额外放大 1.25 倍。
  - 拉动接近上限时按 tanh 曲线逐渐变软，不会硬停。
  - 弯折区间从 [0.1, 0.62] 改为 [0.16, 0.72]：根部更稳，弯曲分布得更长更柔。
